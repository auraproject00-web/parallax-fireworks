# Parallax Fireworks

Game kecil di browser: namamu tampil besar dengan efek parallax 3D, dan setiap klik meluncurkan kembang api lengkap dengan suara.

## Cara main

- Ketik namamu di kotak kanan bawah, lalu tekan **Pakai** (atau Enter).
- Gerakkan mouse untuk efek parallax.
- Klik di mana saja, atau tekan **Kembang Api!**, untuk meluncurkan kembang api.
- **Mute** untuk mematikan suara.

Nama tersimpan di browser untuk kunjungan berikutnya. Kamu juga bisa membagikan link dengan nama yang sudah terisi, misalnya `.../?nama=BUDI`.

## Jalankan di komputer

Buka `CODING/index.html` langsung di browser, atau jalankan server kecil supaya suara pasti termuat:

```sh
python3 -m http.server
```

lalu buka http://localhost:8000.

## Hosting di GitHub Pages

Di repo ini buka **Settings → Pages**, pilih **Deploy from a branch**, branch `main`, folder `/ (root)`, lalu Save. Game akan tersedia di
https://auraproject00-web.github.io/parallax-fireworks/
